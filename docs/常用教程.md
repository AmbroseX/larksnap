# larksnap 常用教程

> 给第一次用的人看。按"你想干什么"分章节，每章先给操作步骤，再说注意事项。
> 还没装扩展的，先看 [安装与使用教程](安装与使用教程.md)，装好、登录过一次飞书再回来。

**先记住三件事：**

- larksnap 是借用你浏览器里**已经登录的飞书**来干活的，不用申请任何权限或 API。
- 所有导出的文件都落到浏览器的**默认下载目录**（Chrome 一般是"下载"文件夹）。
- 侧边栏底部有一条状态栏，导出时的进度、成功、失败都显示在那里。出了问题先看它。

## 1. 打开侧边栏与授权域名

侧边栏是 larksnap 的主界面，所有按钮都在里面。

### 操作步骤

1. 在浏览器里打开一篇飞书文档（网址里带 `docx`、`wiki`、`sheets`、`base` 的页面都行）。
2. 点浏览器工具栏上的 larksnap 图标，右侧弹出侧边栏。也可以按快捷键 `Ctrl/Cmd+Shift+L`。
3. 看侧边栏上方的"当前页"区域：显示出文档标题，类型写着"飞书 docx"之类，就说明认出来了。
4. 如果是公司自建域名的飞书（不是 `feishu.cn` / `larksuite.com`），侧边栏会出一条横幅：
   "检测到私有化飞书部署，需授权访问该域名后才能导出"。点横幅上的 **「授权访问该域名」** 按钮，在浏览器弹窗里选允许。
5. 状态栏变成 **"已授权，可开始导出"**，就可以用了。授权只要做一次，之后同一个域名不用再点。

### 注意

- 授权过的域名会出现在设置页的"已信任的私有化域名"列表里，可以在那里撤销。
- 公有云飞书（`xxx.feishu.cn`、`xxx.larksuite.com`）不需要授权，打开侧边栏就能直接用。
- 如果侧边栏显示"此页面为浏览器保留页面，扩展无法在此操作"，说明你打开的是 `chrome://` 之类的浏览器内部页，换到正常网页再试。
- 侧边栏显示"无法识别当前页面，请在飞书文档页面操作"时，多半是你打开的是文件夹列表页或首页，而不是某一篇文档。点进文档再试。

## 2. 导出一篇文档（Markdown / PDF / HTML）

这是最常用的功能。三种格式的区别先说清楚：

| 你想要什么 | 点哪个按钮 | 得到什么文件 |
|---|---|---|
| 以后还要改、要放进笔记软件、要喂给 AI | **导出为 Markdown** | 一个 `.zip`（里面是 `.md` 文件和 `images/` 图片文件夹），或者单个 `.md` |
| 原样打印、发给别人看、不打算再改 | **导出为 PDF** | 一个 `.pdf` |
| 想双击就能在浏览器里看，而且只要一个文件 | **导出为 HTML** | 一个 `.html`，图片已经塞在文件里面，离线能看 |

### 操作步骤

1. 打开文档页面，点 larksnap 图标打开侧边栏。
2. 在"当前页"区域点 **「导出为 Markdown」**、**「导出为 PDF」** 或 **「导出为 HTML」** 之一。
3. 看底部状态栏，它会依次显示"正在拉取文档内容..."、"正在下载 N 张图片..."、"正在打包 zip（N 个文件，M MB）..."。
4. 状态栏显示 **"Markdown 导出完成"**（或 "PDF 导出完成" / "HTML 导出完成"），文件就已经在下载目录里了。
5. Markdown 得到的是 zip 的话，解压出来，`.md` 文件里的图片是相对路径，指向旁边的 `images/` 文件夹，两者要放在一起。

也可以不开侧边栏，直接在文档页面点右键，菜单里 **LarkSnap → 导出为 Markdown / 导出为 PDF / 导出为 HTML**，效果一样。

### 图片是打包进去还是留链接？

这是 Markdown 导出独有的选择。打开设置页（扩展图标上右键 → 选项），找 **「导出 Markdown 时的图片处理」**：

- **下载图片到本地（随 zip 打包）**：默认选项。图片下载下来放进 `images/` 文件夹，`.md` 里用相对路径引用。离线能看，推荐。
- **保留在线链接**：不下载图片，`.md` 里保留飞书的图片网址。文件小，只有一个 `.md`，但图片链接需要登录飞书才能打开，而且可能过期。

PDF 和 HTML 没有这个选择，图片总是打包进文件里。

### 注意

- **两条导出通道。** 如果你的公司开着飞书官方导出功能，扩展优先走官方通道，Markdown 会得到单个 `.md` 文件，状态栏显示"Markdown 导出完成（官方）"；PDF 由飞书服务端排版，效果最接近原文。如果公司关了官方导出，扩展会自动改读页面数据自己转换，状态栏会先提示"该文档官方导出已关闭，将通过页面数据导出（请确保你已获授权）"。**请只在你有权限的文档上这样做。**
- **PDF 太长会压画质。** 自己转换的 PDF 遇到很长的文档，会显示"PDF 导出完成（文档较长，已压缩清晰度以完整收录）"，这是为了把全文装进去，不是出错。
- **文档里有画板时。** 画板是浏览器实时画出来的，导出时扩展要把画板滚到屏幕上截一张图。如果看到"画板未能抓取（请把画板滚动到可见区域后重试，或在飞书里另存为图片手动插入）"，照提示做一遍再导。含画板的 PDF 会自动改走自己转换这条路，画板才清晰。
- **内嵌表格。** 文档里嵌的电子表格会被读成 Markdown 表格。读不到时会降级成一个"查看内嵌表格"的链接，不会让整篇导出失败。
- **部分图片下载失败。** 状态栏会显示"Markdown 导出完成（图片 3/10，部分失败已降级为在线链接）"，失败的图片在 `.md` 里会是在线链接。全部失败多半是域名没授权到位，重新授权后再导一次。
- **右键菜单或快捷键导出的结果**显示在扩展图标的角标上：绿 ✓ 成功，红 ! 失败。失败原因打开侧边栏才能看到。

## 3. 导出表格和多维表格

飞书的"电子表格"（网址带 `sheets`）和"多维表格"（网址带 `base`）跟普通文档完全不同，导出方式也不一样。

| 类型 | 能导出成什么 | 点哪个按钮 |
|---|---|---|
| 电子表格（sheets） | 一个 `.zip`：一份 Markdown（每张表一个标题 + 表格）+ `csv/` 文件夹（每张表一个 CSV） | **导出为 Markdown** |
| 多维表格（base） | 一个 `.xlsx`，每张数据表一个 sheet | **导出为 Excel** |

### 操作步骤

1. 打开表格页面，**等它完全加载出来**，能看到单元格里的内容再动手。
2. 点 larksnap 图标打开侧边栏。
3. 电子表格点 **「导出为 Markdown」**；多维表格点 **「导出为 Excel」**。
4. 状态栏显示"正在读取表格数据（页面内存）..."，接着"正在打包..."。
5. 看到 **"表格导出完成（N 张表）"** 或 **"多维表格导出完成（N 张表）"** 就好了。

### 注意

- **按钮点错了会被挡住。** 在电子表格上点 PDF / HTML / 导出附件，会提示"电子表格暂只支持导出 Markdown（含 CSV），PDF / HTML / 附件不适用"；在多维表格上点 Markdown / PDF / HTML / 附件，会提示"多维表格只支持导出 Excel，Markdown / PDF / HTML / 附件不适用"。「导出为 Excel」在普通文档上点也会提示"导出 Excel 仅适用于多维表格"。
- **只能导出页面已经加载的数据。** 表格的内容是飞书推到页面里的，扩展是从页面读，不是从服务器拉。所以：
  - 表格还没加载完就点，会报"未能读取到表格数据（页面可能未加载完成）"，等一会再点。
  - **多维表格很大时（几千行以上）**，页面一开始只加载前一部分。导出会成功，但状态栏会说"大表仅导出已加载的 N/M 行，滚动加载后重试可导全"。这时在表格里往下滚到底，让它把行都加载出来，再导一次。
- 你在页面上看不到的内容（没权限的表、被隐藏的列），导出里也不会有。
- 提示"表格是空的，或未读到任何单元格"时，确认你打开的表确实有内容，刷新页面再试。

## 4. 导出文档里的附件和图片

想把一篇文档里插的图片、Word、PDF、压缩包等文件一次性全下下来，用这个。

### 操作步骤

1. 打开文档页面，打开侧边栏。
2. 点 **「导出附件」**（按钮下面的小字是"批量下载图片和文件"）。
3. 状态栏显示"正在收集附件列表..."，然后"正在下载附件 3/12..."。
4. 看到 **"附件导出完成（12/12）"**，下载目录里会多一个以"文档标题-附件"命名的 `.zip`，解压就是全部文件。

### 注意

- 这个功能只对普通文档（docx / wiki 里的文档）有效，电子表格和多维表格不适用。
- 文档里没有任何图片和文件时，会提示"该文档没有可导出的附件"，这不是错误。
- 显示"附件导出完成（10/12）"表示有 2 个没下下来，多半是网络波动或者那个文件你没权限。重导一次通常能补上。
- 全部失败会提示"所有附件下载失败，请重试"，先确认域名授权是不是到位（见第 1 章），尤其是公司自建域名。
- 图片和附件数量很多（几百个）时，下载和打包都要等一会，别关侧边栏，看状态栏慢慢走。

## 5. wiki 知识库里的文档

知识库（网址是 `/wiki/xxxx`）里的页面，外表看起来都一样，但里面装的可能是文档、电子表格或多维表格。扩展会自己去问飞书"这个节点里装的是什么"，然后按对应类型处理，你不用管。

### 操作步骤

1. 在知识库里点进你要导出的那一页（要点到具体页面，不是知识库目录）。
2. 打开侧边栏，确认"当前页"显示的标题是这一页的标题。
3. 装的是文档：按第 2 章操作，点 **「导出为 Markdown」/「导出为 PDF」/「导出为 HTML」**。
4. 装的是电子表格：点 **「导出为 Markdown」**，得到 Markdown + CSV 的 zip（同第 3 章）。
5. 装的是多维表格：点 **「导出为 Excel」**。

### 注意

- 一次只导当前这一页，**不会把整个知识库或子页面一起导出**。想导多篇，一篇一篇来，或者用第 6 章的命令行方式让 Claude Code 帮你批量跑。
- 知识库里的表格页，网址一直是 `/wiki/...`，不会跳到 `/sheets/...`，这是正常的，扩展照样认得出来。
- 知识库页面认不出类型时，刷新页面、等加载完再打开侧边栏。
- 没有这一页的查看权限，导出会失败，扩展不能绕过权限。

## 6. 在 Claude Code 里用 larksnap-fetch 后台抓取

装了 larksnap-fetch 技能后，可以在 Claude Code 里贴一个飞书链接，让它在后台把文档抓到本地文件夹，不用你去点侧边栏。原理是：命令行把任务交给本机的一个小后台程序（daemon），再由它通知浏览器里的 larksnap 扩展去导出，所以 **Chrome 必须开着，扩展必须装着并登录过飞书**。

### 操作步骤

1. 安装技能（只做一次）。macOS / Linux 在终端运行：
   ```bash
   curl -fsSL https://raw.githubusercontent.com/AmbroseX/larksnap/main/install.sh | bash
   ```
   Windows 在 PowerShell 运行：
   ```powershell
   irm https://raw.githubusercontent.com/AmbroseX/larksnap/main/install.ps1 | iex
   ```
   它会检查 Node 18+、把技能装到 `~/.claude/skills/larksnap-fetch`、把后台程序注册成开机自启。
2. 确认 Chrome 开着、larksnap 扩展已装、飞书已登录。点一下扩展图标，侧边栏顶部的状态圆点变绿（已连接 daemon）最好；灰色也没关系，第一次跑命令时会自动唤醒。
3. 在 Claude Code 里直接说：
   > 把 `https://xxx.feishu.cn/docx/AbCd1234` 下载到 `./docs`
4. 或者自己在终端跑命令：
   ```bash
   node ~/.claude/skills/larksnap-fetch/scripts/fetch.mjs <飞书链接> <输出目录> [--format md|pdf|html]
   ```
   `--format` 不写就是 `md`。
5. 命令结束后看最后几行：`✓ 已导出到 /绝对路径/文档标题`，下面列出写了哪些文件。

### 输出目录长什么样

`<输出目录>` 是父目录，每篇文档单独一个以标题命名的子文件夹，互不混淆：

```
docs/
└── 无监督数据修复/            ← 文档标题
    ├── 无监督数据修复.md
    └── images/                ← 图片，.md 里用相对路径引用
        └── xxx.png
```

- `--format html`：子文件夹里是一个 `.html`。
- `--format pdf`：子文件夹里是一个 `.pdf`，能不能出取决于你公司有没有开官方导出，不行会自动改用自己转换。
- 链接是电子表格：不管你写什么 `--format`，都得到 Markdown + `csv/` 文件夹。
- 链接是多维表格：得到一个 `.xlsx`。
- 链接不是飞书、是普通网页：自动按"整页转 Markdown"处理，只支持 `md`，图片保留在线链接，不下载（小红书例外，图片会下载到本地，但要用带 `xsec_token` 的完整分享链接）。
- 链接是 arXiv 论文：不走浏览器，用另一个脚本 `scripts/arxiv.mjs`，一次下载 PDF + HTML + Markdown，不需要登录。

### 常见退出码

命令失败时，终端最后一行是一段 JSON，里面的 `hint` 写着下一步该做什么。Claude Code 会自己读，你看前面几行人话就行。

| 退出码 | 意思 | 你要做什么 |
|---|---|---|
| 0 | 成功 | 没事 |
| 1 | 导出失败 | 看提示；多半是文档没权限或网络问题，重跑一次 |
| 2 | 命令写错了 | 检查链接和目录；电脑上同时有多个 Chrome 用户配置时，要加 `--profile <code>`，code 在侧边栏顶部状态圆点点开复制 |
| 3 | 需要登录 | 在 Chrome 里打开这个域名的飞书登录一下，再重跑 |
| 4 | 需要授权域名 | 在 Chrome 打开该域名下任一飞书页面，侧边栏点「授权访问该域名」，再重跑 |
| 5 | 后台程序或扩展没连上 | 确认 Chrome 开着、扩展装着，点一下扩展图标唤醒，再重跑 |

### 注意

- 后台抓取会在 Chrome 里**悄悄开一个标签页**跑导出，跑完自动关。文档里有画板时，那个标签页会短暂切到前台闪一下，是正常现象（画板只有在屏幕上才画得出来）。
- 导出完成后如果 stdout 里多了一行"⚠️ 文档可能不完整……"，说明正文没拉全，含义见第 8 章。
- 一次只能抓一篇。想批量，让 Claude Code 循环跑就行，它会一篇一篇来。
- 侧边栏顶部提示"桥接协议版本不一致：请更新 larksnap-fetch 技能"时，重跑一次安装命令并加 `--update`（Windows 是 `-Update`）：
  ```bash
  curl -fsSL https://raw.githubusercontent.com/AmbroseX/larksnap/main/install.sh | bash -s -- --update
  ```
- 技能还能**往飞书文档里写内容**（新建文档、追加、替换某一段）和**用你的浏览器搜一次网页**，入口分别是 `scripts/edit.mjs` 和 `scripts/search.mjs`。这两个属于进阶用法，在 Claude Code 里直接用自然语言说"把这个 md 追加到某某文档"或"帮我搜一下某某"，它会自己调。编辑时会占用系统剪贴板几秒，浏览器顶部会出现"正在调试此浏览器"的横幅，跑完就没了。

## 7. 其它功能一笔带过

这些功能都在侧边栏下半部分的"通用工具"区，在任何网页上都能看到，不限于飞书。

| 功能 | 在哪里 | 一句话说明 |
|---|---|---|
| **整页转 Markdown** | "网页剪藏"组，按钮「复制」/「下载 .md」；或页面右键 LarkSnap → 整页转 Markdown；快捷键 `Ctrl/Cmd+Shift+M` | 把当前网页正文转成 Markdown。勾上「仅选中内容」只转你选中的那段。设置页可以选图片保留链接还是内嵌。 |
| **整页截图** | "截图"组，按钮「整页长图 PNG」/「导出 PDF」；快捷键 `Ctrl/Cmd+Shift+S` | 自动滚动逐屏抓取拼成一张长图存到下载目录。第一次用会弹一个"所有网站"权限请求，必须选允许，浏览器规定截屏只认这种权限。无限滚动的页面可以设"截取时长上限"。 |
| **AI 总结 / AI 对话** | "AI 总结"组，「打开 AI 对话」 | 把当前页正文交给你自己配的 AI 接口总结、追问。**必须先在设置页填自己的 OpenAI 兼容接口地址、API Key 和模型名**，扩展不自带任何 AI 服务，不填就完全不可用、不发任何请求。 |
| **解除复制限制** | "页面开关"组 | 不让选、不让复制、不让右键的网页，开一下就能复制了，关掉恢复原状。 |
| **选中文字自动复制** | "页面开关"组 | 开着的话，选中超过 N 个字就自动进剪贴板。字数和格式在设置页调。 |
| **复制标签页链接** | "网页剪藏"组，「复制本页链接(MD)」/「复制全部标签页」 | 把当前页或所有打开的标签页的标题和网址复制出来，格式在设置页选。 |
| **YouTube 字幕** | 在 YouTube 视频页打开侧边栏，"当前页"区域出现「导出字幕（YouTube）」卡片 | 选字幕语言，点「下载 .md」。视频没字幕时会退化成"标题+简介"。 |

## 8. 常见问题

### 导出完成了，但状态栏多了一句"⚠️ 文档可能不完整"，什么意思？

这是 2026 年 10 月新加的提示，针对**超长文档**。飞书是分页把正文给扩展的，扩展一页一页翻着拉。以前翻到一定页数就停，停了也不吭声，导出的文件就少了后半段却显示成功。现在上限提高了很多（约 24 万个段落），并且拉不全时会明说。会出现三种话：

- **"⚠️ 文档可能不完整：翻页达到上限，后半部分未拉到"**——文档实在太长，超过了扩展的翻页上限。这种文档极少见，建议分段导出或用飞书自带的导出。
- **"⚠️ 文档可能不完整：翻页提前结束"**——飞书中途不再给新内容了，可能是网络抖动或者接口限制。等一会再导一次，通常能全。
- **"⚠️ 表格内容可能不全：子树补拉超过上限"**——文档里某个表格太大，格子没拉完。正文是全的，只是那个表格可能缺行。

这三句只会在扩展自己读页面数据转换时出现；走飞书官方导出通道（见第 2 章）不会有。在 Claude Code 里用命令行抓取时，这些提示会打在命令输出的最后几行。

### 侧边栏显示"上次任务已中断（超过 10 分钟没有进度），请重试"？

导出过程中侧边栏被关掉又重新打开，而上一次的任务已经超过 10 分钟没有新进度了，扩展就不再假装"还在跑"，直接告诉你中断了。原因多半是浏览器把扩展后台回收了。**直接重新点一次导出按钮就行。** 如果是特别大的文档（几百张图），实际上任务可能还在跑，等一等看下载目录有没有文件出现。

### 进度卡在某个百分比不动（比如 97%）怎么办？

97% 这个点是在"打包 zip"，几百张图片时这一步要几十秒，耐心等一下，状态栏文案里会写着"正在打包 zip（N 个文件，M MB）"，文件数和大小越多越慢。如果等了几分钟还是没动：

1. 不要关侧边栏，看下载目录有没有文件出现（有时文件已经下好了，只是状态没刷新）。
2. 确实没有，就关掉侧边栏重新打开，看到"上次任务已中断"后重新点导出。
3. 还不行，改用右键菜单试一次；或者把"导出 Markdown 时的图片处理"改成"保留在线链接"，先把文字拿到手。
4. 反复卡，点侧边栏底部的「导出诊断信息」把诊断包和文档大小（大概多少页、多少图）一起到项目的 GitHub Issues 反馈。

### 提示"检测到私有化飞书，请先在侧边栏授权访问该域名"？

你用的是公司自建域名的飞书，扩展还没拿到访问这个域名的权限。打开侧边栏，点横幅上的 **「授权访问该域名」**，浏览器弹窗里选允许。授权一次就够了。授权后图片还是全部下载失败的话，再点一次授权（有些图片存在另一个子域名下，重新授权会把它一起带上）。

### 提示"请先登录飞书后再导出"？

浏览器里没有这个域名的飞书登录态。在当前浏览器里（注意是同一个浏览器用户配置）打开飞书，正常登录一次，再回来导出。公开分享出来的文档不登录也能导，私有文档必须登录。

### 提示"官方导出不可用（code 1002）"或"该文档官方导出已关闭"？

你公司在飞书后台关了导出功能。扩展会自动改读页面数据自己转换，Markdown / HTML / PDF 都还能出，只是 PDF 排版是扩展自己排的，和飞书官方导出的有点区别。**请在获得授权的前提下使用。**

### 超大文档（几万字、几百张图）导出要注意什么？

- 别关侧边栏，也尽量别切走标签页，等状态栏跑完。
- 图片特别多时，Markdown 先选"保留在线链接"拿到文字，再单独用「导出附件」把图片批量下下来，分两步比一步更稳。
- PDF 很长时会自动压清晰度，想要高清的用 HTML，或者导 Markdown 后自己转。
- 导出完一定看一眼状态栏有没有"⚠️ 文档可能不完整"，有就按上面说的处理。

### 侧边栏一片空白或认不出文档？

刷新文档页面，等它完全加载出来，再点扩展图标。确认你打开的是文档正文页，不是文件夹列表页。

### 右键菜单导出完，扩展图标上出现红色 !？

那是失败了。打开侧边栏，状态栏里有失败原因。

### 导出的文件不见了？

去浏览器的默认下载目录找（Chrome 右上角的下载图标也能看到）。文件名是文档标题，Markdown 带图片的是 `.zip`，表格也是 `.zip`，多维表格是 `.xlsx`。

### 怎么反馈问题？

侧边栏底部点 **「提交意见和问题」**，会跳到项目的 GitHub Issues。碰到私有化飞书格式不对的问题，先点旁边的 **「导出诊断信息」**，把生成的诊断包一起附上（已去掉个人信息）。
